MoQ AI Voice Agent

マイクで話しかけると、pipecat の bot が Gemini で聞き取り、考え、声で答える

使い方

BrowserMic ↔ RelayMoQT ↔ pipecat botPython ↔ GeminiSTT / LLM / TTS

  1. pipecat bot を起動する

    Gemini API キーを Google AI Studio で取得します。relay は Cloud relay-1 か、make relay で起動したローカルの relay です 

    cd examples/python/moq-ai-voice-agent
GOOGLE_API_KEY=<API キー> uv run python -m moq_ai_voice_agent.bot \
  --relay-url https://relay-1.moqt.research.skyway.io:443

  2. 話しかける

    手元の bot を Cloud relay で使うときは、このページの URL に ?botUrl=http://127.0.0.1:8101 を付けて開き、Join します
