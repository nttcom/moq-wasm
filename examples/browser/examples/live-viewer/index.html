Live Viewer

MoQT Live Viewer

RTMP / SRT から live-ingest bridge が配信した映像を、画質を切り替えながら視聴します。

配信の開始方法

視聴する前に、別ターミナルで配信を開始します。

各コマンドは別々のターミナルで実行します。映像は H.264、音声は AAC を使用してください。 配信経路に合った Relay URL と namespace anon/live/test を選び、Watch を押します。

OBS / ffmpegSRT / RTMP → Cloud Ingestionlive-ingest → Cloud RelayMoQT 

make ffmpeg-srt-bbb-remote

OBS で SRT 配信する場合は、ffmpeg の代わりに次のサーバー URL を設定します。

srt://relay-1.moqt.research.skyway.io:9000?mode=caller&streamid=anon/live/test

OBS で RTMP 配信する場合は、サーバーに rtmp://relay-1.moqt.research.skyway.io:1935/anon/live/test、 ストリームキーに stream を設定します。

視聴先の Relay URL： https://relay-1.moqt.research.skyway.io:443

OBS / ffmpegSRT → Local IngestionGStreamer → Cloud RelayMoQT 

make gst-srt-publish GST_MOQT_URL=https://relay-1.moqt.research.skyway.io:443

make ffmpeg-srt-bbb-local

OBS で SRT 配信する場合は、ffmpeg の代わりに次のサーバー URL を設定します。

srt://localhost:9000?mode=caller&streamid=anon/live/test

ffmpeg のテストパターンを配信する場合は、make ffmpeg-srt-bbb-local の代わりに make ffmpeg-srt を実行します。

視聴先の Relay URL： https://relay-1.moqt.research.skyway.io:443

OBS / ffmpegSRT → Local IngestionGStreamer → Local RelayMoQT 

make relay

make gst-srt-publish GST_MOQT_URL=https://127.0.0.1:4433

make ffmpeg-srt-bbb-local

make browser

make chrome

OBS で SRT 配信する場合は、ffmpeg の代わりに次のサーバー URL を設定します。

srt://localhost:9000?mode=caller&streamid=anon/live/test

ffmpeg のテストパターンを配信する場合は、make ffmpeg-srt-bbb-local の代わりに make ffmpeg-srt を実行します。

視聴先の Relay URL： https://127.0.0.1:4433

配信開始からライブ端までが軸で、下線が relay のキャッシュに残っている再生可能な区間です。 映像にカーソルを合わせるとシークバーと ±1 秒 / ±5 秒のボタンが出ます（キーボードは ← → が 1 秒、↓ ↑ が 5 秒）。⛶ で全画面になります。 --transcode で live-ingest を起動すると歯車から下位画質が選べます。
