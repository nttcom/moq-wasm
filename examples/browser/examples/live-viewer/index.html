配信の開始方法

MP4 ファイルブラウザ → Cloud RelayMoQT

  1. MP4 を配信

    右の MP4 Publish でファイルを選択し Publish

  2. 視聴

    同じ Relay・namespace で Watch

OBSMoQT プラグイン → Cloud RelayMoQT

  1. プラグインを導入

    obs-moqt（OBS 32 以降）

  2. OBS の「ドック → MoQT」に入力

    Relay URL

    moqt://relay.moqt.research.skyway.io:443

    Namespace は右の Track Namespace と同じ値 · Token は下のボタンでコピー（1 時間有効）

  3. 配信開始

    Use for streaming → 配信開始

  4. 視聴

    同じ namespace で Watch

OBS / ffmpegSRT / RTMP → Cloud Ingestioningest-gateway → Cloud RelayMoQT

  1. 配信開始（ffmpeg / OBS）

    A. ffmpeg
    make ffmpeg-srt-bbb-remote
    B. OBS（SRT URL）
    srt://relay-1.moqt.research.skyway.io:9000?mode=caller&streamid=anon/live/test

    RTMP: rtmp://relay-1.moqt.research.skyway.io:1935/anon/live/test · キー stream

  2. 視聴

    Relay https://relay-1.moqt.research.skyway.io:443 · namespace anon/live/test

OBS / ffmpegSRT → Local IngestionGStreamer → Cloud RelayMoQT

  1. ローカル Ingestion 起動

    make gst-srt-publish GST_MOQT_URL=https://relay-1.moqt.research.skyway.io:443

  2. 配信開始（ffmpeg / OBS）

    A. ffmpeg
    make ffmpeg-srt-bbb-local

    テストパターン: make ffmpeg-srt

    B. OBS（SRT URL）
    srt://localhost:9000?mode=caller&streamid=anon/live/test

  3. 視聴

    Relay https://relay-1.moqt.research.skyway.io:443 · namespace anon/live/test

OBS / ffmpegSRT → Local IngestionGStreamer → Local RelayMoQT

  1. ローカル Relay 起動

    make relay

  2. ローカル Ingestion 起動

    make gst-srt-publish GST_MOQT_URL=https://127.0.0.1:4433

  3. 配信開始（ffmpeg / OBS）

    A. ffmpeg
    make ffmpeg-srt-bbb-local

    テストパターン: make ffmpeg-srt

    B. OBS（SRT URL）
    srt://localhost:9000?mode=caller&streamid=anon/live/test

  4. 視聴

    make browser

make chrome

    Relay https://127.0.0.1:4433 · namespace anon/live/test
