Live Viewer

MoQT Live Viewer

RTMP / SRT から live-ingest bridge が配信した映像を、画質を切り替えながら視聴します。

配信の開始方法

視聴する前に、別ターミナルで配信を開始します。

クラウドRelay利用

https://relay-1.moqt.research.skyway.io:443

make relay は不要です。トークンなしで配信できます。

RELAY=https://relay-1.moqt.research.skyway.io:443

# gateway をどれか選ぶ
# LIVE_INGEST_MOQT_URL=$RELAY make live-ingest
# LIVE_INGEST_MOQT_URL=$RELAY make live-ingest-transcode   # 下位画質も配信
# GST_MOQT_URL=$RELAY make gst-srt-publish                 # SRT のみ

# 配信元をどれか選ぶ
# make ffmpeg-rtmp
# make ffmpeg-srt
# make ffmpeg-srt-bbb
make browser

ローカルRelay利用

https://127.0.0.1:4433

make relay で relay を起動します。自己署名証明書なので Chrome は make chrome で開きます。 

make relay

# gateway をどれか選ぶ
# make live-ingest
# make live-ingest-transcode   # 下位画質も配信
# make gst-srt-publish         # SRT のみ

# 配信元をどれか選ぶ
# make ffmpeg-rtmp
# make ffmpeg-srt
# make ffmpeg-srt-bbb
make browser
make chrome

Playback

-
--:-- --:-- / --:-- LIVE

配信開始からライブ端までが軸で、下線が relay のキャッシュに残っている再生可能な区間です。 映像にカーソルを合わせるとシークバーと ±1 秒 / ±5 秒のボタンが出ます（キーボードは ← → が 1 秒、↓ ↑ が 5 秒）。⛶ で全画面になります。 --transcode で live-ingest を起動すると歯車から下位画質が選べます。
