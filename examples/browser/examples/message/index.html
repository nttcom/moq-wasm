低レベル API · Message

MoQT の制御メッセージを 1 つずつ送る

MoqSession のリクエストを画面から 1 つずつ送り、Relay の応答と受信したオブジェクトを確かめます。2 つのタブで開くと、片方で Publish したトラックをもう片方で Subscribe できます。

Namespace

Track Namespace の告知と購読

announce

PUBLISH_NAMESPACE。PUBLISH_NAMESPACE_DONE で取り下げます

watchNamespaces

SUBSCRIBE_NAMESPACE。UNSUBSCRIBE_NAMESPACE で止めます

Publish

トラックを用意してオブジェクトを書き込む

publishTrack

トラックへの SUBSCRIBE / FETCH / TRACK_STATUS に応答します。チェックすると PUBLISH も送ります

Subscribe

トラックを購読・取得する

subscribe

SUBSCRIBE。forward は SUBSCRIBE_UPDATE で切り替え、UNSUBSCRIBE で終えます

fetch

FETCH。End Object 0 は End Group 全体を指します

trackStatus

TRACK_STATUS

接続

最後のリクエスト

受信したオブジェクト

コンソール

info / warn / error
