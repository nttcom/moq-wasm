MoQ Chat Moderation

pipecat の bot が Jev でチャットを判定し、暴言にラベルを付ける

モデレーターの起動方法

pipecat の bot は relay と一緒にローカルで起動します

各コマンドは別々のターミナルで実行します。bot には Jev の API キーが必要です

BrowserChat ↔ Local RelayMoQT ↔ pipecat botJev

  1. relay を起動する

    make relay

  2. Jev の API キーを設定する

    cd examples/python/moq-chat-moderation
cp .env.example .env

    .env の JEV_API_KEY にキーを書きます。.env は git 管理外です

  3. モデレーターを起動する

    uv run --env-file .env python -m moq_chat_moderation.bot --insecure

    --insecure はローカル relay の自己署名証明書を検証しない指定です

  4. チャットに参加する

    make chrome で起動した Chrome でこのページを開き、Local relay-a を選んで Join します。 モデレーター接続済みになったら送信できます
