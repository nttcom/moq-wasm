AI 連携 · Chat Moderation

AI がチャットを読み、ラベルを付ける

pipecat の bot が d1-2B でチャットの発言を判定してラベルを付け、「暴言」と判定したメッセージを削除します。Relay に参加し、モデレーターが接続したら送信できます。

使い方

Cloud Run の d1-2B は停止後の最初の判定に時間がかかります

BrowserChat ↔ Cloud RelayMoQT ↔ pipecat botCloud Run ↔ Cloud Rund1-2B

  1. チャットに参加する

    Relay URL は既定の Cloud relay-1 のまま Join します。モデレーター接続済みになったら送信できます

BrowserChat ↔ Local RelayMoQT ↔ pipecat botPython ↔ Cloud Rund1-2B

  1. d1-2B を Cloud Run にデプロイする

    https://github.com/nttcom/moq-wasm/blob/master/examples/python/system-one-on-cloud-run.md

  2. relay を起動する

    ローカルの relay を選んだページは、手元の bot にルームの bot を頼みます。各コマンドは別々の ターミナルで実行します 

    make relay

  3. モデレーターを起動する

    cd examples/python/moq-chat-moderation
uv run python -m moq_chat_moderation.bot --insecure \
  --system-one-url "$(gcloud run services describe moqt-system-one --region asia-southeast1 --format 'value(status.url)')/v1/systemone" \
  --gcloud-auth

    gcloud のアカウントに roles/run.invoker が必要です

  4. チャットに参加する

    make chrome で起動した Chrome でこのページを開き、Local relay-a を選んで Join します。モデレーター接続済みになったら送信できます
