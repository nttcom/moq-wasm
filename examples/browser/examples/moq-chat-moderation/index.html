MoQ Chat Moderation

pipecat の bot が djev-run でチャットを判定し、暴言を削除する

モデレーターの起動方法

pipecat の bot はローカルで起動します

各コマンドは別々のターミナルで実行します。gcloud のアカウントに roles/run.invoker が必要です。停止後の最初の判定は約 3 分かかります

BrowserChat ↔ Cloud RelayMoQT ↔ pipecat botPython ↔ Cloud Rundjev-run

  1. モデレーターを起動する

    cd examples/python/moq-chat-moderation
uv run python -m moq_chat_moderation.bot \
  --relay-url https://relay-1.moqt.research.skyway.io:443 \
  --jev-url "$(gcloud run services describe djev-dgemma --region asia-southeast1 --format 'value(status.url)')/v1/systemone" \
  --gcloud-auth

  2. チャットに参加する

    Relay URL は既定の Cloud relay-1 のまま Join します。モデレーター接続済みになったら送信できます

BrowserChat ↔ Local RelayMoQT ↔ pipecat botPython ↔ Cloud Rundjev-run

  1. relay を起動する

    make relay

  2. モデレーターを起動する

    cd examples/python/moq-chat-moderation
uv run python -m moq_chat_moderation.bot --insecure \
  --jev-url "$(gcloud run services describe djev-dgemma --region asia-southeast1 --format 'value(status.url)')/v1/systemone" \
  --gcloud-auth

    --insecure はローカル relay の自己署名証明書を検証しない指定です

  3. チャットに参加する

    make chrome で起動した Chrome でこのページを開き、Local relay-a を選んで Join します。 モデレーター接続済みになったら送信できます
