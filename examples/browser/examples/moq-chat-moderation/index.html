MoQ Chat Moderation

pipecat の bot が djev-run でチャットを判定し、暴言を削除する

使い方

Cloud Run の djev-run は停止後の最初の判定に約 3 分かかります

BrowserChat ↔ Cloud RelayMoQT ↔ pipecat botCloud VM ↔ Cloud Rundjev-run

  1. チャットに参加する

    Relay URL は既定の Cloud relay-1 のまま Join します。モデレーター接続済みになったら送信できます

BrowserChat ↔ Local RelayMoQT ↔ pipecat botPython ↔ Cloud Rundjev-run

  1. djev-run を Cloud Run にデプロイする

    https://github.com/nttcom/moq-wasm/blob/master/examples/python/djev-run-on-cloud-run.md

  2. relay を起動する

    Cloud relay-1 には Cloud の bot がつながっているため、手元の bot はローカルの relay につなぎます。各コマンドは別々のターミナルで実行します 

    make relay

  3. モデレーターを起動する

    cd examples/python/moq-chat-moderation
uv run python -m moq_chat_moderation.bot --insecure \
  --jev-url "$(gcloud run services describe djev-vision --region asia-southeast1 --format 'value(status.url)')/v1/systemone" \
  --gcloud-auth

    gcloud のアカウントに roles/run.invoker が必要です

  4. チャットに参加する

    make chrome で起動した Chrome でこのページを開き、Local relay-a を選んで Join します。 モデレーター接続済みになったら送信できます
