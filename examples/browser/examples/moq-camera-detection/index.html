MoQ Camera Detection

カメラ映像についての質問に、pipecat の bot が djev-vision で答える

判定サーバの起動方法

pipecat の bot はローカルで起動します

各コマンドは別々のターミナルで実行します。gcloud のアカウントに roles/run.invoker が必要です。停止後の最初の判定は約 3 分かかります

BrowserCamera ↔ Cloud RelayMoQT ↔ pipecat botdjev-vision

  1. 判定サーバを起動する

    cd examples/python/moq-camera-detection
uv run python -m moq_camera_detection.bot \
  --relay-url https://relay-1.moqt.research.skyway.io:443 \
  --djev-url "$(gcloud run services describe djev-vision --region asia-southeast1 --format 'value(status.url)')/v1/chat/completions" \
  --gcloud-auth

  2. カメラを配信する

    Relay URL は既定の Cloud relay-1 のまま Join します

BrowserCamera ↔ Local RelayMoQT ↔ pipecat botdjev-vision

  1. relay を起動する

    make relay

  2. 判定サーバを起動する

    cd examples/python/moq-camera-detection
uv run python -m moq_camera_detection.bot --insecure \
  --djev-url "$(gcloud run services describe djev-vision --region asia-southeast1 --format 'value(status.url)')/v1/chat/completions" \
  --gcloud-auth

  3. カメラを配信する

    make chrome で起動した Chrome でこのページを開き、Local relay-a を選んで Join します
