映像送信の開始方法
映像が表示されないときは、別ターミナルで ONVIF カメラの映像を配信します。
クラウドRelay利用
https://relay-1.moqt.research.skyway.io:443
make relay は不要です。トークンなしで配信できます。
RELAY=https://relay-1.moqt.research.skyway.io:443

# ONVIF_IP / ONVIF_USERNAME / ONVIF_PASSWORD は .env に設定しておく
ONVIF_MOQT_URL=$RELAY make onvif
make browser
ローカルRelay利用
https://127.0.0.1:4433
make relay で relay を起動します。自己署名証明書なので Chrome は make chrome で開きます。 
make relay

# ONVIF_IP / ONVIF_USERNAME / ONVIF_PASSWORD は .env に設定しておく
make onvif
make browser
make chrome
