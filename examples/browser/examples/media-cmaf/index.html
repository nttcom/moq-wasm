CMAF トラックを MSE で再生

LOC トラックと並べて CMAF パッケージのトラックを Publish し、Subscriber は Media Source Extensions で再生します。2 つのタブで開き、同じ Track Namespace を使ってください。

Publisher

カメラを createBroadcast() の cmaf: true で Publish します。

  • camera と camera_cmaf を同じ catalog に並べる
  • キーフレーム間隔を 0.5 / 1 / 2 秒から選択

Subscriber

CMAF の映像を LivePlayer で MSE に流して再生します。

  • catalog の CMAF トラックを Subscribe
  • 再生統計を表示
  1. Publisher で Relay に接続し、getUserMedia のあと Publish します
  2. 表示された Track Namespace をコピーします
  3. Subscriber に貼り付けて Subscribe します
