Datagram vs Stream

同じカーソル位置と送信時刻を subgroup ストリームと datagram の 2 トラックで流し、受信を左右に並べる

使い方
  1. Relay を選んで「開始」を押します。このページが 2 トラックを publish し、relay 経由で自分で subscribe します
  2. パッドの上でマウスを動かします。「自動で動かす」を有効にすると円を描いて動きます
  3. 輪がこのページの今のカーソル、塗りの点が relay から届いた位置です。遅延は送信時刻と受信時刻の差で、同じページの時計なので片道の時間です
  4. 差を見るにはパケットロスを入れます。macOS は Network Link Conditioner、Linux は sudo tc qdisc add dev <dev> root netem loss 5% delay 30ms を使います。ストリームは再送を待って止まり、datagram は欠けるだけで遅れません
