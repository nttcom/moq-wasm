低レベル API · Media

映像と音声を MSF ブロードキャストで送受信

Publisher がカメラとマイクを MSF の catalog と LOC トラックとして Publish し、Subscriber が catalog からトラックを選んで再生します。2 つのタブで開き、同じ Track Namespace を使ってください。

Publisher

カメラ・マイク・画面共有を createBroadcast() で Publish します。

  • catalog / video / audio / video_timeline / chat を Publish
  • 映像のミュートと画面共有への切り替え

Subscriber

catalog を Subscribe してトラックを選び、LivePlayer で再生します。

  • catalog から映像・音声トラックを選択
  • 受信状況と再生統計を表示
  1. Publisher で Relay に接続し、getUserMedia のあと Publish します
  2. 表示された Track Namespace をコピーします
  3. Subscriber に貼り付け、catalog とトラックを Subscribe します
