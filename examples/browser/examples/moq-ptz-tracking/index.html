MoQ PTZ Tracking

指定した対象が中央に来るよう、pipecat の bot が djev-vision で PTZ カメラを動かす

使い方

Cloud Run の djev-vision は停止後の最初の判定に約 3 分かかります

PTZ Cameraonvif-ingest ↔ Local RelayMoQT ↔ pipecat botPython ↔ Cloud Rundjev-vision

  1. djev-run を Cloud Run にデプロイする

    https://github.com/nttcom/moq-wasm/blob/master/examples/python/djev-run-on-cloud-run.md

  2. relay を起動する

    各コマンドは別々のターミナルで実行します

    make relay

  3. PTZ カメラを配信する

    .env に ONVIF_IP・ONVIF_USERNAME・ONVIF_PASSWORD を設定します

    make onvif

  4. pipecat bot を起動する

    cd examples/python/moq-ptz-tracking
uv run python -m moq_ptz_tracking.bot --insecure \
  --djev-url "$(gcloud run services describe djev-vision --region asia-southeast1 --format 'value(status.url)')/v1/chat/completions" \
  --gcloud-auth

    gcloud のアカウントに roles/run.invoker が必要です

  5. 追従する対象を指定する

    make chrome で起動した Chrome でこのページを開き、Local relay-a のまま Join します
