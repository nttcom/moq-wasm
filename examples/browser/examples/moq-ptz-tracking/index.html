MoQ PTZ Tracking

指定した対象が中央に来るよう、pipecat の bot が d3-flash で PTZ カメラを動かす

使い方

Cloud Run の d3-flash は停止後の最初の判定に約 2 分 40 秒かかります

Browserこのページ ↕ PTZ Cameraonvif-ingest ↔ Cloud RelayMoQT ↔ pipecat botCloud VM ↔ Cloud Rund3-flash

  1. PTZ カメラを Cloud relay-1 に配信する

    .env に ONVIF_IP・ONVIF_USERNAME・ONVIF_PASSWORD を設定します

    make onvif ONVIF_MOQT_URL=https://relay-1.moqt.research.skyway.io:443

  2. 追従する対象を指定する

    Relay URL は既定の Cloud relay-1 のまま Join します

Browserこのページ ↕ PTZ Cameraonvif-ingest ↔ Local RelayMoQT ↔ pipecat botPython ↔ Cloud Rund3-flash

  1. d3-flash を Cloud Run にデプロイする

    https://github.com/nttcom/moq-wasm/blob/master/examples/python/d3-flash-on-cloud-run.md

  2. relay を起動する

    Cloud relay-1 には Cloud の bot がつながっているため、手元の bot はローカルの relay につなぎます。各コマンドは別々のターミナルで実行します 

    make relay

  3. PTZ カメラを配信する

    .env に ONVIF_IP・ONVIF_USERNAME・ONVIF_PASSWORD を設定します

    make onvif

  4. pipecat bot を起動する

    cd examples/python/moq-ptz-tracking
uv run python -m moq_ptz_tracking.bot --insecure \
  --d3-flash-url "$(gcloud run services describe d3-flash --region asia-southeast1 --format 'value(status.url)')/v1/systemone" \
  --gcloud-auth

    gcloud のアカウントに roles/run.invoker が必要です

  5. 追従する対象を指定する

    make chrome で起動した Chrome でこのページを開き、Local relay-a を選んで Join します
