使い方

停止後の最初の判定は時間がかかります

Browserこのページ ↕ PTZ Cameraonvif-ingest ↔ Cloud RelayMoQT ↔ pipecat botCloud Run ↔ Cloud Rund1-2B

  1. PTZ カメラを Cloud relay-1 に配信する

    .env: ONVIF_IP / ONVIF_USERNAME / ONVIF_PASSWORD

    make onvif ONVIF_MOQT_URL=https://relay-1.moqt.research.skyway.io:443 \
  ONVIF_AUTH_TOKEN=<共有リンクのトークン> \
  ONVIF_PUBLISH_NAMESPACE=<appId>/moq-ptz-tracking/onvif/client \
  ONVIF_SUBSCRIBE_NAMESPACE=<appId>/moq-ptz-tracking/bots/ptz-tracking/command

  2. 追従する対象を指定する

    Cloud relay-1 のまま Join し、「bot を参加させる」を押す

Browserこのページ ↕ PTZ Cameraonvif-ingest ↔ Local RelayMoQT ↔ pipecat botPython ↔ Cloud Rund1-2B

  1. d1-2B を Cloud Run にデプロイ

  2. relay を起動

    make relay

  3. PTZ カメラを配信する

    .env: ONVIF_IP / ONVIF_USERNAME / ONVIF_PASSWORD

    make onvif \
  ONVIF_AUTH_TOKEN=<共有リンクのトークン> \
  ONVIF_PUBLISH_NAMESPACE=<appId>/moq-ptz-tracking/onvif/client \
  ONVIF_SUBSCRIBE_NAMESPACE=<appId>/moq-ptz-tracking/bots/ptz-tracking/command

  4. pipecat bot を起動する

    bot サービス（services/bots）の BOTS_TYPES に登録します（README）

  5. 追従する対象を指定する

    Local relay-a で Join し、「bot を参加させる」を押す

    make chrome
