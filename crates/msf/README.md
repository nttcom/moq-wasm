# msf

Types for the MSF catalog (draft-ietf-moq-msf-01) and its CMAF profile
(draft-ietf-moq-cmsf-01): `Catalog`, `Track`, `Packaging`, `TrackRole` and the
`MediaTimelineRecord` of the media timeline track. Used by the publishers, the
relay E2E tests and, through `crates/moqt-client-wasm`, the browser examples.
