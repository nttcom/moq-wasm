# msf

Types for the MSF catalog (draft-ietf-moq-msf-01) and its CMAF profile
(draft-ietf-moq-cmsf-01): `Catalog`, `Track`, `InitData`, `Packaging`,
`TrackRole` and the `MediaTimelineRecord` of the media timeline track. It
also holds what the drafts fix for every publisher, such as the `catalog`
track name and the CMAF sibling of a track.
